1. Executive Summary

Trackr is a comprehensive, full-stack web application designed to help job seekers organize, visualize, and systematically track their job application pipelines. The platform provides an interactive analytics dashboard with real-time metrics, a complete CRUD interface for managing job records, and secure JWT-based authentication — enabling users to monitor applications from initial submission through to offer stage.

Key Value Proposition: Trackr replaces fragmented spreadsheet-based job tracking with a purpose-built, cloud-hosted dashboard that provides conversion rates, pipeline visualization, and data export capabilities.

2. System Architecture Overview

The application follows a three-tier client-server architecture using the MERN stack. The frontend (Presentation Layer), backend API (Application Layer), and database (Data Layer) are fully decoupled and communicate exclusively via RESTful HTTP APIs.

11. Functional Requirements

11.1 Authentication Module

  • FR-1.1: Users can register with name, email, and password. Duplicate emails are rejected.
  • FR-1.2: Users can log in with email/password. JWT issued as HTTP-Only cookie (30-day expiry).
  • FR-1.3: Users can log out. JWT cookie is cleared server-side.
  • FR-1.4: Protected routes redirect unauthenticated users to the login page.

11.2 Job Management Module

  • FR-2.1: Users can create job entries with company, role, status, source, and optional job URL.
  • FR-2.2: Users can view all their jobs in a searchable, filterable, sortable table.
  • FR-2.3: Users can update job details and status to reflect pipeline progression.
  • FR-2.4: Users can delete job records with confirmation dialog.
  • FR-2.5: Users can auto-import job details by pasting a job URL (LinkedIn, Naukri support).
  • FR-2.6: Users can export filtered job data as a CSV file.

11.3 Dashboard & Analytics Module

  • FR-3.1: Display aggregate counts: Total, Applied, Interview, Offer, Rejected.
  • FR-3.2: Render an interactive donut/pie chart showing pipeline distribution.
  • FR-3.3: Calculate and display Interview Rate and Success Rate as percentages with progress bars.
  • FR-3.4: Show the 3 most recent job entries as a quick activity feed.

12. Non-Functional Requirements

IDCategoryRequirement
NFR-1SecurityPasswords hashed using bcrypt with 10 salt rounds. JWT stored in HTTP-Only, Secure, SameSite cookies.
NFR-2SecurityAll job CRUD operations enforce ownership validation (job.user === req.user._id).
NFR-3PerformanceDashboard metrics computed via MongoDB Aggregation Pipeline for efficient server-side computation.
NFR-4ScalabilityStateless JWT authentication allows horizontal scaling of the backend.
NFR-5UsabilityFully responsive UI across desktop, tablet, and mobile breakpoints.
NFR-6MaintainabilityMVC-inspired backend structure with separated routes, controllers, models, and middleware.
NFR-7AvailabilityDeployed on managed cloud platforms (Render + Vercel) with automatic scaling.
